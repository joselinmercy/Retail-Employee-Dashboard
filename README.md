# Retail Sales & Inventory Dashboard

## Project Overview
This project is built using Power BI, MySQL, and Excel datasets to analyze retail sales, inventory, customers, and staff performance.

## Tools Used
- Power BI
- MySQL
- Excel
- Power Query

## Dashboards
### 1. Retail Sales & Inventory Dashboard
- Total Products
- Total Orders
- Total Stock
- Category Analysis
- Store-wise Inventory

### 2. Customer & Staff Performance Dashboard
- Customer Distribution
- Orders by Staff
- State-wise Customers
- Store Performance

## Dataset Tables
- Brands
- Categories
- Customers
- Orders
- Order Items
- Products
- Stocks
- Staff
- Stores
