# Retail Employee Dashboard

## Project Overview
This project is created using Power BI and MySQL to analyze retail employee and store data.

## Tools Used
- Power BI
- MySQL
- SQL
- Power Query

## Features
- KPI Cards
- Employee Store Analysis
- Active Status Analysis
- Interactive Filters
- Dashboard Visualization
